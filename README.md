# チャットボット HTML 生成・管理ツール（簡易CMS）

ブラウザだけで動く、チャットボットウィジェットのデザイン設定 → プレビュー → 単一HTMLファイル書き出しツールです。
外部ライブラリは一切使用せず、HTML / CSS / Vanilla JavaScript のみで実装しています。

## 使い方

`index.html` をブラウザで開くだけです（サーバー不要 / ダブルクリックで動作）。

## 機能

### 1. 設定パネル（左サイドバー）
- **基本設定**: ボット名 / ヘッダーロゴ文字 / サブタイトル / 自動応答バッジ文言
- **デザインカスタマイズ**:
  - メインカラー（カラーピッカー＋HEX入力＋プリセット、初期値 `#e28238`）— 文字・枠線・バッジの基準色
  - 塗りのスタイル: **単色 / グラデーション** の切り替え。グラデーションは開始色・終了色・角度（0〜360°）を指定でき、プリセット6種とライブプレビュー付き
  - ヘッダー・ボタン上の文字色
  - **パーツごとの色指定**: ヘッダー／起動ボタン／ユーザー吹き出し／送信ボタン／選択肢を、それぞれ「メインに追従」または好きな色に個別設定
  - 閉じている時のボタン文言（初期値「質問する」）、デモ用ダミーページ背景の同梱有無
- **チャットシナリオ**: 最初のボット発言 / 選択肢とボットの返信（追加・削除可）/ 戻る選択肢 / 入力欄プレースホルダー / 注意事項テキスト
- **ファイル出力設定**: 出力ファイル名（初期値 `bakuraku_chatbot.html`）
- **ボタン**: 「プレビュー更新」「HTMLファイルとしてダウンロード」「現在の設定を一覧に保存」

### 2. プレビュー（右エリア）
- iframe 内で **書き出されるHTMLそのもの** を表示するため、プレビュー＝出力結果。
- 入力すると自動でプレビューが更新されます（明示的な「プレビュー更新」ボタンもあり）。
- 実際に開閉トグル・選択肢クリック・自由入力の挙動を確認できます。
- PC / スマホ幅の切り替え、生成HTMLコードの表示に対応。

### 3. 保存済み設定一覧（簡易CMS）
- LocalStorage（キー: `chatbot_cms_items_v1`）に設定を保存し、一覧表示。
- 一覧から「呼び出して再編集」「削除」、および「新規設定」「すべて削除」が可能。
- 呼び出し中の設定に対して保存すると上書き更新されます。

### 4. HTMLファイルの書き出し
「HTMLファイルとしてダウンロード」で、色・文字・シナリオデータ・CSS・JavaScript がすべて埋め込まれた
**単体で即時動作するHTMLファイル** を Blob 経由でダウンロードします。

### 5. 設定データ（JSON）の書き出し・読み込み
- **現在の設定をJSONで書き出し**: `{ type:"chatbot-cms-config", version, exportedAt, config }` 形式で1件を出力
- **保存済みをすべてJSONで書き出し**: `{ type:"chatbot-cms-collection", version, exportedAt, items:[…] }` 形式で全件を出力
- **JSONファイルを読み込み**: 1件のJSONは編集フォームへ、複数件のJSONは保存済み一覧へ取り込み（同じIDは上書き、無ければ追加）

読み込み時は欠損項目を既定値で補完するため、旧バージョンで書き出したJSONもそのまま読み込めます。
不正なJSONはエラーメッセージを表示し、既存の設定は変更しません。

## 生成されるHTMLの構成

- 画面右下に固定されるフローティングウィジェット（`position: fixed`, `z-index` 最上位）
- 閉じている時: メインカラーのカプセル型ボタン（指定文言＋チャットSVGアイコン）
- 開いた時: ヘッダー（ロゴ / タイトル / サブタイトル / 自動応答バッジ / 閉じる×）、メッセージログ、
  選択肢エリア、フッター（入力欄＋送信アイコン＋注意事項）
- 選択肢は横に折り返すコンパクトなピル型。エリアの高さは最大 132px で、入りきらない場合のみスクロールし、
  下端がフェードしてスクロール可能なことを示します（メッセージ表示領域を圧迫しません）
- 色は CSS 変数で統一（`--cbw-main` / `--cbw-on-main` / `--cbw-choice` / `--cbw-fill-header` / `--cbw-fill-launcher` / `--cbw-fill-user` / `--cbw-fill-send`）。
  グラデーション指定時はヘッダー・起動ボタン・ユーザー吹き出し・送信ボタンの背景に `linear-gradient` が入り、
  枠線・文字など単色が必要な箇所には代表色を使用します
- JavaScript: 開閉トグル、選択肢クリックによるシナリオ進行（ユーザー発言→タイピング表示→ボット返信→
  タイムスタンプ付与→自動スクロール）、Esc キーで閉じる、自由入力への応答

生成HTMLのテキストはすべて HTML エスケープして埋め込まれ、シナリオデータは JSON として埋め込まれます。
