# English Steps — 高校生のためのレベル別英語学習アプリ

日本の高校1年生が **A2 Key for Schools / B1 Preliminary for Schools / B2 First for Schools** に向けて、
Reading・Listening・Writing・Speaking の4技能を技能別のレベルで学ぶ Web アプリです。
**iPhone の縦画面と Safari を第一基準**に設計し、教員向けの一覧・教材編集は PC の広い画面にも対応しています。

> このアプリはケンブリッジ英語検定に向けた**自主教材**です。Cambridge University Press & Assessment の公式製品ではなく、
> 同機構とは関係ありません。診断結果・習熟度はアプリ独自の目安であり、Cambridge English Scale のスコアや合否を示すものではありません。
> 本文・スクリプト・問題はすべて独自に作成しており、公式問題は転載していません。

## 起動方法

必要なもの: **Node.js 22.13 以上**（外部の npm パッケージは使っていません。`npm install` は不要です）

```bash
cd english-app
npm run seed-demo   # 開発用デモデータ（任意）: demo-teacher / demo-student、パスワード demo-pass-123、参加コード DEMO2026
npm start           # http://127.0.0.1:3000/
```

| 環境変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` / `HOST` | `3000` / `127.0.0.1` | 待ち受けポート・アドレス。同じ Wi-Fi の iPhone から試すときは `HOST=0.0.0.0` |
| `DB_FILE` | `data/app.db` | SQLite データベースのファイル |
| `NODE_ENV` | — | `production` で Secure Cookie・HSTS を有効化 |
| `COOKIE_SECURE` | 本番のみ `1` | `1` で Cookie に Secure 属性を付ける（HTTPS 必須） |
| `ORG_NAME` | — | 個人情報の取り扱いに表示する**運営者（学校名）**。本番では必ず設定 |
| `PRIVACY_CONTACT` | — | 開示・削除などの**問い合わせ窓口**。本番では必ず設定 |
| `RETENTION_TEXT` | 既定の文言 | 保存期間の説明（学校の規程に合わせて設定） |

### 本番運用の前に
1. **HTTPS で公開**してください（iPhone の録音機能は HTTPS でしか動きません。Cookie の保護にも必要です）。リバースプロキシ（nginx など）で TLS を終端し、`NODE_ENV=production` で起動します。
2. 教員アカウントを作成します（生徒はクラス参加コードで自分で登録します）。
   ```bash
   npm run create-user -- --role teacher --login t-sato --name "佐藤先生"   # パスワードは対話入力
   npm run create-user -- --role admin --login admin01 --name "管理者"
   ```
3. `ORG_NAME`・`PRIVACY_CONTACT`・`RETENTION_TEXT` を設定し、個人情報の取り扱い画面（`#/privacy`）の内容を学校の規程・担当者と確認してください。
4. 保存期間を過ぎたデータの削除: `npm run purge-inactive -- --days 400 --dry-run`（確認後 `--dry-run` を外して実行）。
5. `data/app.db` を定期的にバックアップしてください（個人情報を含むため、保管場所のアクセス権に注意）。

### iPhone 実機で試す（開発時）
`HOST=0.0.0.0 npm start` で起動し、同じネットワークの iPhone の Safari で `http://<PCのIP>:3000/` を開きます。
HTTP 接続では録音機能が使えないため、Speaking は自動的に「録音なしで練習」になります（HTTPS なら録音できます）。
ホーム画面に追加すると、アプリのように全画面で使えます（PWA。Service Worker は HTTPS のときだけ登録します）。

## 技術構成と判断

| 項目 | 選択 | 理由 |
|---|---|---|
| サーバー | Node.js 標準の `http` のみ（依存パッケージなし） | 既存リポジトリの「外部ライブラリなし」の方針に合わせ、サプライチェーンのリスクを減らす |
| データベース | Node.js 組み込みの `node:sqlite`（SQLite） | 1ファイルで運用でき、トランザクションで整合性を保てる |
| 画面 | HTML + CSS + Vanilla JS（ES Modules、ビルド不要） | iPhone Safari で安定動作。`innerHTML` を使わず DOM を組み立てて XSS を防止 |
| 音声 | ブラウザーの読み上げ（Web Speech API `speechSynthesis`） | 外部の音声生成サービスを使わない。端末内の英語音声を優先 |
| 録音 | `MediaRecorder`（機能検出して利用可能なときのみ） | 録音は**端末内（IndexedDB）にのみ保存**し、サーバーへ送らない |

既存のチャットボット生成ツール（リポジトリ直下の `index.html`）には手を加えず、このアプリは `english-app/` に独立して置いています。

```
  public/        index.html, css/app.css, js/（main.js ルーター, api.js 通信とアウトボックス, local.js 端末内保存,

  content/       units/*.json（教材）, diagnostic.json（診断）, rubrics.json（評価基準）, SCHEMA.md（教材の形式）
  scripts/       create-user.js, seed-demo.js, purge-inactive.js, lint.js, e2e-iphone.mjs, make-icons.mjs

```

| 提出物の評価 | `#/t/submission/:id` | 評価基準（5観点×0〜5点）とコメント。生徒の自己評価・再提出履歴も表示 |
| 教材編集 | `#/t/content` `#/t/content/:id` | 単元の公開/非公開、活動・問題の編集と追加、版の履歴、JSON の書き出し・取り込み |

### iPhone 向けの設計
- 横スクロールなしで全操作が完了（E2E で全画面を確認）。タップ領域は 44〜52px 以上。
- `viewport-fit=cover` と `env(safe-area-inset-*)` で、ノッチ・Dynamic Island・ホームインジケーターに操作が重ならない。
- 入力欄は 17px（Safari の自動拡大を防止）。入力中（キーボード表示中）は下部の固定バーを隠し、提出ボタンは本文中に置く。
- Reading は「本文／設問」の切り替えタブ（上部に固定）。根拠ボタンで本文の該当箇所へ移動。PC 幅では左右に並べて表示。
- 音声は**再生ボタンを押して開始**（自動再生なし）。一時停止は「その行から再開」する方式（iOS の pause の不安定さを回避）。速度切替・最初から再生あり。
- ホバーやドラッグが必要な操作はありません。キーボードだけでも操作できます（ラジオボタン・`details`・フォーカス表示）。

## 教材

`content/units/` に、**「学校生活・部活動」第1単元を A2・B1・B2 の3レベル分**収録しています（すべて独自作成）。
Speaking 以外（語彙・解説・Reading・Listening・Writing・試験形式の確認）は各単元に3セットずつあり、1ステップ5〜10分の20ステップ構成です（1単元の目安は A2 約135分・B1 約163分・B2 約187分）。
選択式問題の正答位置が偏らないよう、正答の位置をばらつかせています（解説が「A は〜」のように記号で選択肢を説明している問題は、記号がずれないよう元の順序のままです）。

| 単元 | 内容 | 問題数 |
|---|---|---|
| A2 My School, My Club | 語彙37（3セット）・解説9項目（頻度の副詞・前置詞・can/like -ing・過去形・going to・must/have to・比較 など）・Reading 3本（140〜152語）・Listening 3本（140〜161語）・Writing 3題（25〜45語）・Speaking 質問4・確認問題3セット | 69問 |
| B1 Finding Your Place: Joining a Club | 語彙42・解説10項目（過去形と現在完了・理由と結果・意見・条件文・助言・受動態・used to など）・Reading 3本（270〜299語）・Listening 3本（229〜244語）・Writing 3題（記事・メール返信・物語、80〜110語）・Speaking 3問・確認問題3セット | 72問 |
| B2 Should Club Activities Be Compulsory? | 語彙42・解説10項目（論の組み立て・譲歩・ヘッジング・対比・仮定法・伝達の受動態・強調構文 など）・Reading 3本（361〜412語）・Listening 3本（276〜299語）・Writing 3題（エッセイ・記事・報告書、140〜190語）・Speaking 3問・確認問題3セット | 75問 |

各問題に正答・日本語の解説（誤答の選択肢がなぜ違うか）・根拠（本文やスクリプト中の文字列と完全一致をテストで確認）・問題の種類・難度・学習目標を設定しています。
教材は「テーマ × CEFR レベル × 技能 × 活動の種類」で管理し、`content/SCHEMA.md` の形式の JSON を追加するだけで新しいテーマ（旅行・地域・環境・テクノロジー・進路・異文化交流など）を増やせます（起動時に未登録の単元だけ取り込み、教員の編集内容は上書きしません）。

## データモデル

| 概念 | テーブル | 補足 |
|---|---|---|
| User / Role | `users`（role: student / teacher / admin）, `sessions` | パスワードは scrypt ハッシュ、セッショントークンは SHA-256 ハッシュのみ保存 |
| Class / Enrollment | `classes`（参加コード・受付可否）, `enrollments` | 教員は担当クラスの生徒だけ閲覧可 |
| ExamTarget | `exam_targets` | A2 / B1 / B2 / 未定、受験予定月 |
| LearningUnit | `units` | テーマ・レベル・試験・公開状態・版 |
| LearningObjective | `objectives` | 単元ごとの「できるようになること」。問題から参照 |
| Activity | `activities` | 単元内の step（初期教材は 1〜20）。同じ種類を複数置ける。本文・スクリプト・課題などを JSON で保持。版あり |
| Question | `questions` | 固有 ID と**版（version）**。CEFR・技能・テーマ・試験・難度・学習目標・問題の種類 |
| ContentVersion | `content_versions` | 単元・活動・問題の**全版の内容**を保存（編集者・日時つき） |
| Rubric | `rubrics` | Writing / Speaking × A2 / B1 / B2、各5観点 |
| Answer / Attempt | `attempts` | **解答時の問題の版**、支援の有無（スクリプト表示・音声なし）、何回目か、`client_id`（二重提出防止） |
| 提出済み回答 | `submissions` | Writing / Speaking。`revision` と `parent_id` で**再提出**を区別、解答時の課題の版 |
| DraftAnswer | `drafts` | 提出とは別に保存する下書き（提出すると削除） |
| Feedback | `feedback` | 教員評価（観点別点数・コメント）。`source` 列で将来の AI 推定評価と区別できる |
| SkillProgress | `skill_progress` | 技能ごとの学習レベルと決定根拠（初期値 / 診断 / 生徒 / 教員）。習熟度は毎回算出 |
| ReviewSchedule | `review_items` | 復習の箱番号・次回予定日・理由 |
| カードの解答 | `card_attempts` | 単語帳の小テストの解答（`client_id` で二重記録防止）。カードは教材の語彙と構文（`patterns`）から毎回作るため、別テーブルに持たない |
| スタンプ | `stamps` | 問題またはカードごとに1つ。レベル・種類・獲得日時。一度もらうと消えない |
| そのほか | `diagnostic_results`, `activity_completions` | 診断結果（方法: 自動採点 / 自己評価）、活動の完了 |

### スタンプと称号（`server/stamps.js`・`server/cards.js`）
- **スタンプの条件**（問題・カードごと）: スクリプトなどの支援を使わない正解が**3回以上連続**し、その連続が**2日以上にまたがる**こと（日付は日本時間）。その場で3回続けて解いただけでは取れません。まちがえるか支援を使うと連続はリセットされますが、一度もらったスタンプは消えません。
- 対象は単元の問題（語彙・文法・Reading・Listening・試験形式の確認）と、単語帳の小テスト（単語・熟語・構文）です。Writing・Speaking は正誤がないため対象外です。
- **称号**はレベル（A2・B1・B2）ごとに、そのレベルでもらえるスタンプ総数に対する割合で決まります: ビギナー（1個）→ ブロンズ 20% → シルバー 40% → ゴールド 60% → プラチナ 80% → マスター 100%。ゴールド以上になると、次のレベルへの挑戦を案内します。
- 生徒同士の比較（ランキング）はありません。

### 習熟度の算出方法（`server/mastery.js`）
- **Reading / Listening**: 生徒の現在の学習レベルの問題について、問題ごとに直近3回の解答を「支援なしで正解 1.0 / スクリプトを見て正解・音声なしで正解 0.5 / 不正解 0」で平均し、さらに問題間で平均。3問未満は「データ不足」として判定しない。0.5 未満「重点的に練習」、0.8 未満「力がついてきている」、それ以上「安定」。
- **Writing / Speaking**: 教員評価（5観点×0〜5点）の平均で判定。自己評価しかない場合は「自己評価のみ（参考値）」として別に表示し、教員評価と混ぜない。
- 4技能を平均して1つの級にはしません。生徒には判定の根拠を平易な文で表示します。
- 「今日やること」は、①未設定なら目標設定、②未受験なら診断、③期限の来た復習、④最も弱い技能の、その技能のレベルの単元の未完了課題、⑤目標レベルの単元の次のステップ、の順に最大3件を理由つきで提示します（`server/services.js`）。

## 個人情報保護・セキュリティ

個人情報保護法（APPI）と GDPR の主な要件に対し、アプリ側で次の対応をしています。**最終的な適合性の判断は、運営者（学校）と法務・情報セキュリティの担当者による確認が必要です。**

| 要件 | 対応 |
|---|---|
| 利用目的の特定・通知（APPI 17・21条 / GDPR 13条） | 登録前に「個人情報の取り扱い」を表示し同意を取得。版を管理し、改定時は再同意を求める |
| データ最小化（GDPR 5条） | 本名・メール・住所・位置情報を集めない。表示名はニックネーム。録音はサーバーに送らない |
| 安全管理措置（APPI 23条 / GDPR 32条） | scrypt によるパスワードハッシュ、HttpOnly・SameSite=Strict（本番は Secure）Cookie、CSRF 対策（独自ヘッダー＋Origin 確認）、ログイン試行制限、CSP など各種セキュリティヘッダー、教員は担当クラスのみ閲覧、入力値の検証、XSS 対策（`innerHTML` 不使用を Lint で検査） |
| 第三者提供の制限（APPI 27条） | 外部サービス（解析・広告・AI・CDN・外部フォント）に一切送信しない（Lint で外部 URL を検査） |
| 開示・データポータビリティ（APPI 33条 / GDPR 15・20条） | 設定画面から自分のデータを JSON でダウンロード |
| 訂正（APPI 34条 / GDPR 16条） | 表示名・目標・レベルを本人が変更可能 |
| 削除・利用停止（APPI 35条 / GDPR 17条） | 生徒自身の退会で全データを完全削除。教員・管理者も削除依頼に対応可能。保存期間を過ぎたデータの削除スクリプト |
| 保存期間の制限（GDPR 5条） | `RETENTION_TEXT` で明示、`purge-inactive` で削除 |
| 未成年への配慮（GDPR 8条） | 保護者と一緒に確認するよう案内。保護者同意の取得は学校の運用で行う想定 |
| 端末内のデータ | 下書き・未送信の回答・録音は端末内に保存し、ログアウト時に削除（共用端末への配慮）。Service Worker は API の応答をキャッシュしない |

運営者（学校）側で必要な対応: 運営者名・窓口の設定、保護者への説明と同意の取得方針、EU 居住者が利用する場合の適法根拠・越境移転の確認、アクセス権限とバックアップの管理、漏えい時の報告手順の整備。

### E2E の結果（iPhone 13 のエミュレーション: 390×844・タッチ・モバイル UA、Chromium）

## 実装状況

### 第1段階（初期版）— 実装済み
iPhone Safari 向け Web アプリ／生徒・教員の画面／目標設定／4技能の簡易診断／A2・B1・B2 の完全な第1単元／回答・解説・学習履歴／技能別の進捗表示／基本的な教材編集／データの永続化（SQLite）／Writing の下書き保持／音声・録音が使えない場合の代替手段

### 第2段階 — 実装済み
復習の自動提案（間隔反復）／Writing・Speaking の教員評価／Speaking の録音（端末内保存）／クラス単位の分析（誤答の多い問題）／教材の JSON 入出力／ホーム画面に追加できる PWA 構成

### 未実装
- **模擬試験**（時間を計って試験形式で通しで解く機能）
- **AI 添削・AI による推定評価**、**音声認識**、**対話型の Speaking 練習** — 外部サービスへの個人データ送信を伴うため、導入時は事前の検討と同意が必要です。未接続の機能は画面に表示していません（`feedback.source` 列などで将来の追加に備えた構造のみ）
- **外部 LMS との連携**
- 教員・管理者アカウントの画面からの作成（現在はコマンドで作成）、クラスから生徒を外す画面操作（API のみ）
- 2つ目以降の単元・テーマ（構造は対応済み）

### 仮定したこと
- 対象は日本の高校1年生（未成年）で、学校が運営者となり、担当教員がクラスを作って参加コードを配布する運用。
- 生徒の本人確認は学校の運用（ログインIDの付け方など）で行い、アプリには本名を保存しない。
- Listening の音声は、実在の録音ではなく端末の読み上げ機能で生成する（話者ごとに声の高さを変える）。
- 教材は全教員で共有し、どの教員も編集できる。
- 診断の Writing・Speaking は初期版では自己評価。教員はあとから生徒のレベルを調整できる。
